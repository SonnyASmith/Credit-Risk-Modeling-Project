# Running Locally

## 1) Download all the code files and directories contained within this folder

## 2) Install any dependencies not currently in your system (use 'npm install' or manually install)

### Dependencies: 
### Minimum to run: 

#### Node.js Version 18

### See 'Package.json' for a full list of dependencies

## 3) Open the command prompt, and navigate to the directory where you saved the code, and enter 'npm run dev'

## 4) Open a web browser and enter the URL: http://127.0.0.1:5000/

## 5) To stop the program, return to the command prompt and hit Ctrl + C, then enter 'Y' to terminate the batch job
